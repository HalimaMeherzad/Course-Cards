🎓 Skill Courses Website

A modern and responsive Skill Courses website created as a frontend practice project to improve HTML and CSS skills.

Note: This is a practice project, not a complete commercial website. The main purpose of this project was to practice creating a clean course-card layout, responsive design, spacing, typography, and using icons in a web interface.

🌐 Project Overview

The website presents a collection of sample online courses in different categories.

Each course card includes:

* 🖼️ Course image
* 📚 Course title
* ⭐ Rating
* 💬 Number of reviews
* ⏱️ Course duration
* 🔗 Enrollment link
* 🔹 Icons for visual details

✨ Features

* 🎨 Clean and modern UI
* 📚 Course card-based layout
* ⭐ Rating and review information
* ⏱️ Course duration
* 🔗 Enrollment call-to-action
* 🔹 Icons used throughout the interface
* 📱 Fully responsive layout
* 🖥️ Desktop layout
* 📲 Tablet layout
* 📱 Mobile layout
* 🖼️ Organized image assets
* 📐 Consistent spacing and alignment
* ✨ Hover effects and transitions

📱 Responsive Design

The project was developed with responsive design in mind and adapted for different screen sizes using CSS Media Queries.

🖥️ Desktop

A multi-column grid layout is used to display the course cards.

📲 Tablet

The layout adjusts the number and size of cards to fit tablet screens comfortably.

📱 Mobile

The course cards adapt to smaller screens while maintaining readable text, spacing, and a user-friendly layout.
